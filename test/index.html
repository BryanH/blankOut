Blank Out

Prevent links with the blank attribute from opening in new windows† when clicked.
Why? Because when a link opens in a new window†, the user cannot use the back button to go back to the previous screen.
Some uninformed designers believed 'disabling' the back button and leaving a window open from the site made it sticky, so visitors would be more likely to stay on the site. While this might've worked for click-bait junk sites, it is annoying to regular users when the browser's back-button doesn't work as expected, and they suddenly have many unexpected windows open.
†Note also, this includes new tabs if the browser is configured to do so.
